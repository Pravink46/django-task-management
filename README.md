# Task Management & User Authentication System

A robust full-stack web backend delivering full CRUD operations for task scheduling, tracking, and prioritization. Built with Python, Django, and SQLite.

## Core Features
- Secure session-based authentication & user registration via Django Auth.
- Relational database models using Foreign Keys to isolate task categories per user account.
- Server-side data sanitization and form validation.
- Login-required decorators for data privacy.

## Tech Stack
- Backend: Python, Django
- Database: SQLite
- Frontend Integration: HTML, Bootstrap
